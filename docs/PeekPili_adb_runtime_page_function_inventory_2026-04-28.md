## 5. 开发对齐要点（给后续移植）

- 当前源逆向 App 的主入口是“接口驱动影视首页 + 短剧播放器 + 音乐子系统 + 实验室 + 设置”，不是 B 站三栏结构。
- `https://6800.kstore.vip/fish.json` 对首页源池与搜索源池影响显著，UI 与入口随源配置变化。
- 移植时应优先做到：
- 主底栏 5 Tab 与页面路径一致
- 首页顶部 4 个动作入口（搜索/推送播放/历史/收藏）行为一致
- 搜索源、短剧源、接口配置三类“源选择/管理”面板交互一致
- 音乐模块保留独立 6 Tab 子导航与脚本模式降级逻辑
